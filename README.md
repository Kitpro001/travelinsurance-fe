# Travel Insurance Frontend
Frontend for the Travel Insurance application.

## Tech Stack
- Angular
- TypeScript
- HTML
- CSS
- Bootstrap
- npm

## Prerequisites
- Node.js
- Git
- Angular CLI

## Setup
1. Clone the frontend repository
```
git clone https://github.com/Kitpro001/travelinsurance-fe.git
```

2. Install dependencies
```
npm install
```

3. Run the project.
```
ng serve
```

4. The application will run on:
```
http://localhost:4200
```

5. Continue to setup backend application by referring to the link below:
```
https://github.com/Kitpro001/travelinsurance
```
